알바 지킴이 설계도

프론트엔드와 백엔드 사이의 인터페이스, 데이터 클래스, 호출 흐름 정리. 화면 시안 7개 기준.

1. 전체 구조2. 공통 규칙3. 서비스 인터페이스4. 데이터 클래스5. enum6. 호출 흐름7. 백엔드 내부

1. 전체 구조

화면은 service 패키지의 인터페이스만 호출한다. 백엔드는 인터페이스를 구현한다. 개발 초기에는 Fake 구현으로 화면을 먼저 만들고, 백엔드 완성 후 App.java에서 실제 구현으로 교체한다.

2. 공통 규칙

항목규칙
금액int, 원 단위. 가산수당 등은 항목별로 원 단위 반올림
시간근무시간은 int, 분 단위. 시간 표시 변환은 화면에서 처리
날짜LocalDate, LocalTime, YearMonth
자정 넘는 근무clockOut이 clockIn보다 이르면 다음 날 퇴근으로 계산
없을 수 있는 값반환값은 null 대신 Optional
잘못된 입력백엔드가 ValidationException(메시지) 발생. 화면은 메시지를 알림창으로 표시
데이터 클래스Java record. 생성 후 값 변경 불가. 수정은 새 객체를 만들어 update 메서드에 전달
idWorkRecord, Deduction의 id는 화면에서 UUID.randomUUID().toString()으로 생성
세금·보험합법적으로 뗀 세금·4대보험(3.3% 포함)은 받은 금액 입력 시 따로 받아 덜 받은 돈에서 제외
계산 규칙수당 계산식과 위반 판단 기준은 docs/CALC_RULES.md를 따른다
패키지 변경domain, service 변경은 상대와 합의 후 진행

3.1 RecordService

사용자가 입력한 데이터(근로 조건, 근무 기록, 공제, 받은 금액)의 저장과 조회. 구현: JsonRecordService (백엔드).

메서드반환역할호출 화면
getContract()Optional<Contract>저장된 근로 조건 반환. 없으면 빈 Optional근로 조건 설정, 프로그램 시작 시
saveContract(Contract)void근로 조건 저장. 기존 값은 덮어씀. 시급 0 이하 등은 예외근로 조건 설정
getRecords(YearMonth)List<WorkRecord>해당 월 근무 기록을 날짜순으로 반환. 없으면 빈 목록근무 기록
addRecord(WorkRecord)void근무 기록 추가. 같은 날 여러 건 가능. 근로 조건이 없으면 예외근무 기록
updateRecord(WorkRecord)voidid가 같은 기록을 새 값으로 교체. 해당 id가 없으면 예외근무 기록
deleteRecord(String)voidid로 근무 기록 삭제근무 기록
getDeductions(YearMonth)List<Deduction>해당 월 공제 기록 반환근무 기록
addDeduction(Deduction)void공제 기록 추가. 금액 0 이하면 예외근무 기록
deleteDeduction(String)voidid로 공제 기록 삭제근무 기록
getReceivedPay(YearMonth)Optional<ReceivedPay>해당 월에 입력한 받은 금액 반환. 미입력이면 빈 Optional받은 금액 비교
saveReceivedPay(ReceivedPay)void받은 금액 저장. 같은 월 값은 덮어씀받은 금액 비교

3.2 PayrollService

근로 조건과 근무 기록으로 법정 급여 계산. 구현: DefaultPayrollService (백엔드).

메서드반환역할호출 화면
calculate(YearMonth)PayrollResult해당 월 법정 급여를 항목별로 계산. 사업장 규모에 따라 가산수당 적용 여부 결정. 근로 조건이 없으면 예외. 근무 기록이 없으면 합계 0인 결과대시보드, 급여 상세

3.3 ComparisonService

법정 급여와 실제 받은 금액 비교. 구현: DefaultComparisonService (백엔드).

메서드반환역할호출 화면
compare(YearMonth)Optional<ComparisonResult>calculate 결과와 세전 지급액(입금액 + 세금·보험 공제액)을 비교해 전체 차액과 항목별 차액 계산. 기타 공제 합계도 계산. 받은 금액 미입력이면 빈 Optional대시보드, 받은 금액 비교

3.4 ViolationService

법 위반 의심 항목 검사. 구현: DefaultViolationService (백엔드).

메서드반환역할호출 화면
detect(YearMonth)List<Violation>등록된 위반 규칙을 모두 검사해 위반 의심 항목 목록 반환. 없으면 빈 목록. 받은 금액이 필요한 규칙(주휴수당 미지급 등)은 받은 금액 미입력 시 건너뜀대시보드, 위반 알림

3.5 ReportService

기간별 리포트 파일 생성. 구현: HtmlReportService (프론트엔드). 내부에서 위 네 서비스를 호출해 결과를 모은다.

메서드반환역할호출 화면
export(YearMonth from, YearMonth to, Path dir)Path기간 내 근무 기록, 급여 계산, 비교, 위반 항목을 HTML 파일 하나로 저장하고 파일 경로 반환리포트

3.6 ValidationException

public class ValidationException extends RuntimeException { public ValidationException(String message) { super(message); } }

입력 값이 규칙에 맞지 않을 때 백엔드가 발생시키는 예외. 메시지는 화면에 그대로 표시할 수 있는 문장으로 작성한다. 예: "퇴근 시각이 출근 시각과 같습니다."

4.1 Contract (근로 조건)

계약 내용. 모든 계산의 기준. 한 개만 저장한다.

필드타입역할
workplaceNameString근무지 이름. 화면과 리포트 표시용
hourlyWageint시급. 모든 금액 계산의 기준, 최저임금 비교 대상
startDateLocalDate계약 시작일
endDateLocalDate계약 종료일. 기간 없는 계약은 null. 수습 감액 가능 여부(1년 이상 계약) 판단
workDaysSet<DayOfWeek>계약 근무 요일. 주휴수당의 개근 여부와 1주 계약 근무시간 계산
scheduledStartLocalTime계약 출근 시각
scheduledEndLocalTime계약 퇴근 시각. 조기 퇴근 시간(휴업수당) 계산 기준
scheduledBreakMinutesint계약 휴게시간(분). 1일 계약 근무시간 = 퇴근 - 출근 - 휴게
probationboolean수습 여부
probationEndDateLocalDate수습 종료일. 수습이 아니면 null. 수습 감액 3개월 한도 판단
businessSizeBusinessSize사업장 규모. 연장·야간·휴일 가산과 휴업수당 적용 여부 결정
writtenContractboolean근로계약서 작성 여부. false면 위반 항목으로 표시

4.2 WorkRecord (근무 기록)

실제로 일한 하루 기록 한 건.

필드타입역할
idString기록 식별자. 수정·삭제 대상 지정
dateLocalDate근무 날짜. 월별 조회와 주 단위 묶음 기준
clockInLocalTime실제 출근 시각
clockOutLocalTime실제 퇴근 시각. clockIn보다 이르면 다음 날로 처리
breakMinutesint실제 휴게시간(분). 근무시간에서 제외, 휴게시간 부족 검사
holidayboolean휴일 근무 여부. 사용자가 직접 체크. 휴일수당 계산
earlyLeaveReasonEarlyLeaveReason계약 시간보다 일찍 퇴근한 사유. EMPLOYER_ORDER면 휴업수당 대상
memoString자유 메모. 리포트에 포함

4.3 Deduction (공제 기록)

급여에서 빠진 금액 한 건. 지각 벌금, 유니폼비 등.

필드타입역할
idString기록 식별자
dateLocalDate공제 발생일. 해당 월 판단
amountint공제 금액(양수)
reasonString공제 사유. 부당 공제 위반 메시지에 사용

4.4 ReceivedPay (받은 금액)

한 달 동안 실제로 받은 급여.

필드타입역할
monthYearMonth대상 월
totalAmountint실제 통장 입금액
taxAndInsuranceint세금·4대보험 공제액(3.3% 원천징수 포함). 합법적으로 뗀 금액이라 덜 받은 돈에서 제외. 없으면 0
breakdownMap<PayItem, Integer>급여명세서의 항목별 금액. 명세서가 없으면 빈 Map. 있으면 항목별 비교에 사용

4.5 PayrollResult, PayLine (급여 계산 결과)

calculate의 반환값. PayLine 한 개가 급여 상세 표의 한 줄.

필드타입역할
PayrollResult.monthYearMonth대상 월
PayrollResult.totalWorkMinutesint해당 월 총 근무시간(분). 대시보드 카드 표시
PayrollResult.linesList<PayLine>항목별 계산 내역
PayrollResult.totalint법정 급여 합계
PayLine.itemPayItem항목 종류(기본급, 주휴수당 등)
PayLine.amountint항목 금액
PayLine.descriptionString계산 근거 문장. 예: "76시간 30분 × 10,320원"

4.6 ComparisonResult, ItemDifference (비교 결과)

compare의 반환값. ItemDifference 한 개가 비교 표의 한 줄.

필드타입역할
ComparisonResult.monthYearMonth대상 월
ComparisonResult.legalTotalint법정 급여 합계 (PayrollResult.total)
ComparisonResult.receivedTotalint실제 입금액 (ReceivedPay.totalAmount)
ComparisonResult.grossReceivedint세전 지급액 = 입금액 + 세금·보험 공제액. 법정 급여와 비교하는 기준
ComparisonResult.deductionTotalint해당 월 공제 기록 합계
ComparisonResult.differenceintlegalTotal - grossReceived. 양수면 덜 받은 금액 (기타 공제는 여기에 포함됨)
ComparisonResult.itemsList<ItemDifference>항목별 비교
ItemDifference.itemPayItem비교 항목
ItemDifference.legalAmountint법정 금액
ItemDifference.receivedAmountInteger받은 금액. 항목별 입력이 없으면 null
ItemDifference.differenceintlegalAmount - receivedAmount. receivedAmount가 null이면 0

4.7 Violation (위반 의심 항목)

detect의 반환 목록 원소 하나. 위반 알림 화면의 카드 한 장.

필드타입역할
typeViolationType위반 종류. 화면의 분류 표시
dateLocalDate관련 날짜. 월 전체에 해당하면 null
amountint관련 금액(미지급액, 공제액 등). 금액과 무관하면 0
messageString화면에 표시할 설명 문장
legalBasisString근거 법 조항. 예: "근로기준법 제55조"

  V->>V: 빈 칸 검사
  V->>R: addRecord(WorkRecord)
  alt 입력 오류
    R-->>V: ValidationException
    V-->>U: 알림창 표시
  else 정상
    R->>J: 저장
    V->>R: getRecords(month)
    R-->>V: List~WorkRecord~
    V-->>U: 달력, 목록 갱신
  end

7. 백엔드 내부

수당 계산과 위반 검사를 규칙 클래스로 분리한다. 새 규칙은 클래스 추가 후 RuleSets에 등록한다. 5인 미만이면 RuleSets가 초과근로·가산수당·휴업수당 규칙을 제외한다. 규칙별 계산식과 근거 조항은 docs/CALC_RULES.md(계산 규칙 문서)를 따른다.

클래스역할
PayRule수당 항목 하나를 계산하는 규칙의 공통 인터페이스
ViolationRule위반 유형 하나를 검사하는 규칙의 공통 인터페이스
PayContext규칙에 넘기는 계산 재료. 근로 조건, 해당 월 근무 기록, 최저임금
ViolationContext검사 재료. 근로 조건, 근무 기록, 공제, 받은 금액, 계산 결과
RuleSets사업장 규모에 맞는 규칙 목록 반환. 5인 이상 7개(기본급, 주휴, 초과근로, 연장, 휴일, 야간, 휴업), 5인 미만 2개(기본급, 주휴)
