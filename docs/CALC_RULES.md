# AlbaGuard 계산 규칙

알바 지킴이가 법정 급여를 계산하고 위반을 판단할 때 따르는 규칙을 정리한 문서이다. 각 규칙은 근거 법 조항, 계산식, 적용 범위, 예시, 우리가 정한 가정으로 구성한다.

- 조사일: 2026-11-25
- 본 프로그램의 계산 결과는 참고용이며 법률 자문을 대신하지 않는다.
- 근거 자료는 마지막 장에 정리했다. 법령 원문 외 2차 자료로 확인한 항목은 표시해 두었다.

---

## 1. 적용 대상과 전제

| 항목 | 전제 |
|---|---|
| 근로자 | 근로기준법상 근로자(사용자의 지휘·감독을 받아 일하는 아르바이트) |
| 임금 형태 | 시급제. 통상시급 = 계약 시급으로 본다 |
| 근로계약 | 한 개의 근로 조건(Contract)만 관리한다 |
| 근로관계 | 조회하는 달 이후에도 근로관계가 계속된다고 가정한다 (퇴직 주는 다루지 않음) |
| 금액 단위 | 원. 항목별 금액은 계산 마지막에 원 단위 반올림 |
| 시간 단위 | 분. 시급 계산은 `분 × 시급 ÷ 60` |
| 주의 기준 | 월요일 ~ 일요일 |

### 용어
| 용어 | 뜻 | 프로그램에서 |
|---|---|---|
| 소정근로시간 | 근로계약으로 정한 근무시간 | Contract의 근무 요일, 출퇴근 시각, 휴게시간으로 계산 |
| 실근로시간 | 실제로 일한 시간 | WorkRecord의 출퇴근 시각 - 휴게시간 |
| 단시간근로자 | 1주 소정근로시간이 같은 사업장 통상근로자(주 40시간)보다 짧은 근로자 | 1주 소정근로시간 < 40시간 |
| 1일 소정근로시간 | 계약 퇴근 - 계약 출근 - 계약 휴게 | 예: 18:00~23:00, 휴게 30분 → 270분 |
| 1주 소정근로시간 | 1일 소정근로시간 × 근무 요일 수 | 예: 270분 × 4일 = 1,080분(18시간) |

## 2. 공통 계산

### 2.1 하루 실근로시간
```
시작 = 근무 날짜 + 출근 시각
끝   = 근무 날짜 + 퇴근 시각 (퇴근 시각이 출근 시각보다 이르거나 같으면 다음 날)
실근로 분 = (끝 - 시작) - 휴게 분
```

| 출근 | 퇴근 | 휴게 | 실근로 분 |
|---|---|---|---|
| 18:00 | 23:00 | 30 | 270 |
| 22:00 | 02:00 | 0 | 240 |
| 09:00 | 18:00 | 60 | 480 |

### 2.2 야간 근로시간
- 야간: 22:00 ~ 다음 날 06:00
- 근무 구간과 야간 구간이 겹치는 분을 구한다. 새벽 출근을 위해 전날 22:00 ~ 당일 06:00 구간도 함께 확인한다.
- **가정**: 휴게시간은 야간이 아닌 시간에 사용한 것으로 본다. 근무가 모두 야간이면 휴게시간만큼 야간 분에서 뺀다.

| 출근 | 퇴근 | 휴게 | 야간 분 |
|---|---|---|---|
| 18:00 | 23:00 | 30 | 60 |
| 22:00 | 02:00 | 0 | 240 |
| 05:00 | 09:00 | 0 | 60 |

### 2.3 반올림
- 법에 정한 방법이 없으므로 항목(PayLine)별로 계산한 뒤 원 단위 반올림(0.5 이상 올림)한다.

## 3. 사업장 규모별 적용 규칙

상시 4명 이하 사업장에는 근로기준법 시행령 별표 1에 열거된 조항만 적용된다.

|---|---|---|---|
| 최저임금 | 최저임금법 | 적용 | 적용 |
| 주휴수당 | 근로기준법 제55조 제1항, 제18조 | 적용 | 적용 |
| 휴게시간 | 근로기준법 제54조 | 적용 | 적용 |
| 위약예정 금지, 임금 전액 지급 | 근로기준법 제20조, 제43조 | 적용 | 적용 |

| 휴업수당 | 근로기준법 제46조 | 적용 | **미적용** |

## 4. 법정 급여 계산 규칙

### R1. 기본급 (BASE)
- **근거**: 근로계약, 최저임금법
- **계산**: `그 달 실근로 분 합계 × 시급 ÷ 60`
- **예시**: 4,590분(76시간 30분) × 10,320원 ÷ 60 = **789,480원**

### R2. 주휴수당 (WEEKLY_HOLIDAY)
- **근거**: 근로기준법 제55조 제1항, 제18조 제3항, 시행령 별표 2
- **지급 조건** (모두 충족)
  1. 4주 평균 1주 소정근로시간이 15시간 이상 (계약 기준. 실근로시간 아님)
  2. 그 주의 소정근로일(계약 근무 요일)에 모두 출근
- **개근 판단**
  - 계약 근무 요일 날짜에 WorkRecord가 있으면 출근으로 본다.
  - 지각·조퇴는 결근이 아니므로 개근에 영향을 주지 않는다.
- **계산**
  ```
  주휴 시간 = (1주 소정근로시간 ÷ 40시간) × 8시간   (최대 8시간)
  주휴수당 = 주휴 시간 × 시급
  ```
  단시간근로자의 1일 소정근로시간은 "4주 소정근로시간 ÷ 통상근로자의 4주 소정근로일수(20일)"로 정하며, 위 식과 결과가 같다.
- **주 경계**: 월~일 단위로 나누고, 월말에 걸친 주는 그 주 일요일이 속한 달에 계산한다.
- **예시** (주 18시간, 시급 10,320원)
  - 주휴 시간 = 18 ÷ 40 × 8 = 3.6시간 → 1주 37,152원
  - 4주 개근 → **148,608원**
  - 주 14시간 계약 → 0원
  - 주 40시간 계약 → 8시간 → 82,560원
- **범위 밖**: 퇴직하는 마지막 주의 주휴수당 (행정해석 확인이 필요해 다루지 않음)

### R3. 단시간근로자 초과근로수당 (PART_TIME_OVERTIME) — 신규
- **근거**: 기간제 및 단시간근로자 보호 등에 관한 법률 제6조 제3항
- **대상**: 5인 이상 사업장의 단시간근로자 (1주 소정근로시간 < 40시간)
- **내용**: 소정근로시간을 넘겨 일한 시간에 통상임금의 50% 이상 가산. 주 40시간을 넘지 않아도 적용된다.
- **계산** (하루 단위, 휴일 근무 기록은 제외)
  ```
  그날 소정 분 = 계약 근무 요일이면 1일 소정근로 분, 아니면 0
  초과근로 분 = max(0, min(실근로 분, 480) - 그날 소정 분)
  초과근로수당 = 초과근로 분 × 시급 ÷ 60 × 0.5
  ```
  하루 8시간(480분)을 넘는 부분은 R4 연장근로로 계산해 두 번 가산하지 않는다.
- **예시**: 계약 18:00~23:00인데 24:00 퇴근 → 초과 60분 → **5,160원**
- **참고**: 소정근로시간 초과 근로는 근로자 동의가 필요하고 1주 12시간을 넘을 수 없다 (제6조 제1항).

### R4. 연장근로수당 (OVERTIME)
- **근거**: 근로기준법 제50조, 제56조 제1항
- **대상**: 5인 이상 사업장
- **계산** (휴일 근무 기록은 제외)
  ```
  하루 연장 분 = max(0, 실근로 분 - 480)
  주 연장 분 = max(0, 그 주 실근로 분 합계 - 2,400 - 그 주 하루 연장 분 합계 - 그 주 R3 초과근로 분 합계)
  연장근로수당 = (하루 연장 분 합계 + 주 연장 분) × 시급 ÷ 60 × 0.5
  ```
  같은 시간을 하루 기준, 주 기준, R3에서 중복으로 세지 않는다.
- **예시**
  - 하루 9시간 → 60분 연장
  - 하루 8시간 × 6일(48시간) → 주 기준 480분 연장
  - 하루 10시간 × 5일(50시간) → 하루 기준 600분, 주 기준 추가 없음

### R5. 휴일근로수당 (HOLIDAY)
- **근거**: 근로기준법 제56조 제2항
- **대상**: 5인 이상 사업장, `holiday = true`인 근무 기록
- **휴일의 범위**: 주휴일, 공휴일(5인 이상은 2022년부터 유급휴일). 공휴일 여부는 프로그램이 판단하지 않고 사용자가 직접 체크한다.
- **계산**
  ```
  휴일근로수당 = min(실근로 분, 480) × 시급 ÷ 60 × 0.5
              + max(0, 실근로 분 - 480) × 시급 ÷ 60 × 1.0
  ```
  휴일근로는 R3, R4에 포함하지 않는다. 8시간 초과분의 100% 가산에 연장 가산이 이미 반영되어 있다.
- **예시**: 휴일 10시간 근무 → 8시간 × 5,160 + 2시간 × 10,320 = **61,920원**

### R6. 야간근로수당 (NIGHT)
- **근거**: 근로기준법 제56조 제3항
- **대상**: 5인 이상 사업장
- **계산**: `야간 분(2.2) × 시급 ÷ 60 × 0.5`
- **중복**: 야간 가산은 R3, R4, R5와 별도로 더한다.
- **예시**
  - 18:00~23:00 근무 17일 → 17시간 × 5,160 = **87,720원**
  - 22:00~02:00 하루 → 4시간 × 5,160 = 20,640원

### R7. 휴업수당 (SHUTDOWN_ALLOWANCE)
- **근거**: 근로기준법 제46조, 시행령 제26조
- **대상**: 5인 이상 사업장, `earlyLeaveReason = EMPLOYER_ORDER`인 근무 기록
- **내용**: 사용자 사정으로 근로시간 일부를 쉬게 한 경우, 쉬게 한 시간에 대해 평균임금의 70% 이상 지급
- **계산** (근사)
  ```
  못 일한 분 = 계약 퇴근 시각 - 실제 퇴근 시각
  휴업수당 = 못 일한 분 × 시급 ÷ 60 × 0.7
  ```
- **가정**: 평균임금(직전 3개월 임금 총액 기준) 대신 시급으로 근사한다. 평균임금의 70%가 통상임금을 넘으면 통상임금으로 지급할 수 있다는 단서가 있으나 시급제 아르바이트에서는 근사값과 차이가 작다.
- **예시**: 계약 23:00, 고용주 지시로 21:00 퇴근 → 2시간 × 10,320 × 0.7 = **14,448원**
- 본인 사정 조기 퇴근(PERSONAL)은 0원

## 5. 받은 금액 비교 규칙

### 5.1 세금·보험 공제 처리 — 설계 변경
아르바이트 급여에서는 다음 금액이 합법적으로 빠질 수 있다.
- 4대보험 근로자 부담분, 근로소득세
- 3.3% 원천징수(사업소득 처리)

이 금액까지 "덜 받은 돈"으로 계산하면 잘못된 결과가 나온다. 따라서 받은 금액을 입력할 때 **세금·보험 공제액을 따로 입력**받는다.

```
세전 지급액 = 실제 입금액 + 세금·보험 공제액
차액 = 법정 급여 합계 - 세전 지급액      (양수면 덜 받음)
```

- 지각 벌금, 유니폼비 같은 기타 공제(Deduction 기록)는 세전 지급액에 더하지 않는다. 이 금액은 덜 받은 돈에 포함되고, V7 위반으로도 표시된다.
- 3.3% 공제를 입력한 경우 안내 문구를 표시한다: "지휘·감독을 받으며 일했다면 근로소득으로 보고 4대보험 대상일 수 있습니다." (위반으로 판단하지는 않음)

### 5.2 항목별 비교
```
항목별 차액 = 법정 금액 - 명세서 항목 금액   (명세서 항목 미입력이면 비교하지 않음)
```

### 5.3 예시
| 구분 | 금액 |
|---|---|
| 법정 급여 합계 | 1,025,808원 |
| 실제 입금액 | 838,590원 |
| 세금·보험 공제액 (3.3%, 10원 미만 절사) | 28,610원 |
| 세전 지급액 | 867,200원 |
| 차액 | **158,608원** (주휴수당 148,608 + 지각 벌금 10,000) |

## 6. 위반 감지 규칙

| 번호 | 위반 | 판단 기준 | 근거 | 5인 미만 |
|---|---|---|---|---|
| V1 | 최저임금 미달 | 시급 < 해당 연도 최저임금 (V2 감액 요건 충족 시 90%) | 최저임금법 제6조 | 적용 |
| V2 | 수습 감액 초과 | 수습 중 시급 < 최저임금이면서 ① 계약 기간 1년 미만, 또는 ② 수습 시작 후 3개월 초과, 또는 ③ 시급 < 최저임금 × 90% | 최저임금법 제5조 제2항 | 적용 |
| V3 | 주휴수당 미지급 | 법정 주휴수당 > 0 이고 명세서 주휴수당 < 법정 금액 | 근로기준법 제55조 | 적용 |
| V4 | 가산수당 미지급 | 법정 초과근로·연장·휴일·야간 수당 > 명세서 금액 | 근로기준법 제56조, 기간제법 제6조 | 미적용 |
| V5 | 휴게시간 부족 | 실근로 4시간 이상인데 휴게 30분 미만, 8시간 이상인데 60분 미만 (날짜별) | 근로기준법 제54조 | 적용 |
| V6 | 휴업수당 미지급 | 고용주 지시 조기 퇴근이 있고 명세서 휴업수당 < 법정 금액 | 근로기준법 제46조 | 미적용 |
| V7 | 부당 공제 | 기타 공제(Deduction) 기록 1건당 1건 | 근로기준법 제20조, 제43조 | 적용 |
| V8 | 근로계약서 미작성 | 근로계약서를 작성·교부받지 않음 | 근로기준법 제17조, 기간제법 제17조 | 적용 |

### 세부 사항
- **V1 최저임금**: 연도별 금액은 `MinimumWageTable`에 둔다.

  | 연도 | 시간급 | 근거 |
  |---|---|---|
  | 2025 | 10,030원 | 고용노동부 고시 |
  | 2026 | 10,320원 | 고용노동부 고시 제2025-47호 |
  | 2027 | 10,700원 | 2026-08-05 고시 (2차 자료로 확인) |

- **V2 수습 감액**: 단순노무 업무 종사자는 수습이어도 감액할 수 없다. 프로그램은 업무 종류를 입력받지 않으므로 경고 문구에 이 내용을 안내한다.
- **V3, V4, V6**: 받은 금액을 명세서 항목별로 입력하지 않았으면 판단할 수 없으므로 건너뛴다. 이 경우 총액 차액(5.1)으로만 확인한다.
- **V7 부당 공제**: 정액 지각 벌금은 위약예정에 해당해 무효이고, 법령·단체협약 근거 없는 공제는 근로자 동의가 있어도 임금 전액 지급 원칙에 어긋난다(대법원 2022다219540). 실제로 일하지 못한 시간에 비례한 임금 차감만 허용되며, 이는 R1에서 이미 실근로 기준으로 반영된다. 메시지는 "위반 의심"으로 표시한다.
- **V8 근로계약서**: 단시간근로자는 근로일과 근로일별 근로시간까지 서면에 명시해야 한다(기간제법 제17조 제6호). 프로그램은 작성 여부만 확인한다.

## 7. 전체 계산 예시

**근로 조건**: 시급 10,320원, 월·수·금·토 18:00~23:00, 휴게 30분, 5인 이상, 2026년 11월
**근무**: 계약일 17일 모두 계약대로 근무, 4주 개근

| 항목 | 계산 | 금액 |
|---|---|---|
| 기본급 (R1) | 270분 × 17일 = 4,590분 × 10,320 ÷ 60 | 789,480원 |
| 주휴수당 (R2) | 3.6시간 × 10,320 × 4주 | 148,608원 |
| 초과근로수당 (R3) | 계약 시간 초과 없음 | 0원 |
| 연장근로수당 (R4) | 하루 8시간, 주 40시간 초과 없음 | 0원 |
| 휴일근로수당 (R5) | 휴일 근무 없음 | 0원 |
| 야간근로수당 (R6) | 60분 × 17일 = 17시간 × 5,160 | 87,720원 |
| 휴업수당 (R7) | 해당 없음 | 0원 |
| **합계** | | **1,025,808원** |

같은 조건으로 **5인 미만**이면 R3~R7이 빠져 **938,088원**이다.

## 8. 다루지 않는 것

| 항목 | 이유 |
|---|---|
| 연차유급휴가, 퇴직금 | 1년 이상 근속 기준이라 월 단위 계산 범위 밖 |
| 세금·4대보험 금액 계산 | 사용자가 공제액을 직접 입력 (5.1) |
| 퇴직 주의 주휴수당 | 행정해석 확인 필요 |
| 평균임금 계산 | 휴업수당은 시급으로 근사 (R7) |
| 공휴일 자동 판단 | 사용자가 휴일 근무를 직접 체크 |
| 쉬는 공휴일의 유급휴일 수당 | 5인 이상 사업장에서 소정근로일인 공휴일에 쉬면 유급이나, 공휴일 판단이 필요해 제외 |
| 월급제, 포괄임금제 | 시급제 아르바이트만 대상 |
| 단순노무 업무 여부 | 입력받지 않음 (V2 안내 문구로 대체) |

## 9. 설계 변경 사항

계산 규칙 조사 결과에 따라 설계도를 아래와 같이 바꾼다.

| 대상 | 변경 | 이유 |
|---|---|---|
| `PayItem` | `PART_TIME_OVERTIME("초과근로수당")` 추가 | R3 단시간근로자 초과근로 가산 |
| 수당 규칙 | `PartTimeOvertimeRule` 추가, `RuleSets`의 5인 이상 목록에 등록 | R3 |
| `ReceivedPay` | `int taxAndInsurance` (세금·보험 공제액) 필드 추가 | 5.1 세금·보험 공제를 덜 받은 돈에서 제외 |
| `ComparisonResult` | `int grossReceived` (세전 지급액) 필드 추가, `difference = legalTotal - grossReceived` | 5.1 |
| `MinimumWageTable` | 2025, 2026, 2027년 금액 등록 | V1 |
| 받은 금액 비교 화면 | 세금·보험 공제액 입력 칸 추가 | 5.1 (프론트엔드) |
